# IceCreamProject

## Login and Registration
- `login.html` contains a Bootstrap login form.
- `register.html` contains a registration form.
- `js/auth.js` validates required fields, email format, password length, and matching passwords.
- This is front-end validation only; no real database authentication is implemented yet.

## Product Search
- Search bar added to the home page.
- JavaScript filters the product cards dynamically while the user types.
- If no flavor matches, a Bootstrap warning message is displayed.
